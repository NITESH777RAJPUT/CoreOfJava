# Core Java Conditional Statements

Each `.java` file is a standalone example with its own `main` method. Compile
and run an example from this folder, for example:

```text
javac IfElse.java
java IfElse
```

- `IfElse.java` — `if`, `if-else`, `else-if` chains and nested conditions
- `SwitchStatement.java` — traditional `switch`, `case`, `break`, `default`,
  shared cases and switch expressions (Java 14+)
- `TernaryOperator.java` — conditional expressions that produce a value
- `LogicalConditions.java` — relational and logical operators, short-circuit
  evaluation and String comparison

Conditions in Java must evaluate to `boolean`. Use `equals()` to compare the
contents of Strings; `==` checks whether two object references are identical.
